# Bonsai Local

**Bonsai Local** — неофициальное Android-приложение для локального запуска
Ternary-Bonsai-2-27B на ARM64-смартфоне.

## Возможности

- локальный inference 27B GGUF без облачного API;
- загрузка модели и генерация в фоне с постоянным уведомлением;
- сохранение открытого чата; кнопка «Назад» возвращает к управлению моделью;
- PQ2_0 и PTQ1_0;
- экспериментальный GPU через Vulkan для PTQ1_0, выключен по умолчанию;
- контекст 4K–256K, FP16/Q4 KV и настройка CPU-потоков;
- изображения через отдельный Q8 mmproj;
- опциональные `web_search` / `web_fetch`;
- скачивание до 8 соединений с паузой и докачкой;
- импорт уже скачанного файла через системный файловый менеджер;
- отдельное удаление PTQ1_0, PQ2_0 и mmproj;
- встроенный benchmark prompt/generation tok/s;
- веса моделей не входят ни в APK, ни в репозиторий.

## Начальные настройки

**PQ2_0 · 16K · KV FP16 · CPU 4/8 · reasoning выключен.**

### Экспериментальный GPU (1.2.0)

Перед загрузкой выберите **PTQ1_0 → GPU · Vulkan → 8 слоёв**.
Доступны также 16, 32 и все слои. Для PQ2_0 пока используется CPU.
Приложение проверяет выделение Vulkan-буферов модели и вычислений; число слоёв
в статусе берётся из отчёта движка. Часть операций может выполняться на CPU.
При ошибке остановите движок и выключите GPU.

Сравнивайте скорость встроенным бенчмарком на одинаковой модели и контексте.
Совместимость и ускорение требуют проверки на устройстве; результаты GPU на
телефоне для этого выпуска пока не измерены.
