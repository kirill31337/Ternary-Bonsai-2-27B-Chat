# Contributing

Contributions are welcome. Keep changes focused, testable and
security-conscious.

1. Never commit model weights, API keys, signing keystores or user data.
2. Keep model/runtime revisions and SHA-256 values pinned.
3. Add or update tests for behavior changes.
4. Run `bash tests/run_all.sh` before opening a pull request.
5. Preserve third-party notices when updating the runtime or bundled Web UI.
6. Treat model output and web content as untrusted input.

AI-assisted contributions are welcome, but the contributor remains responsible
for reviewing correctness, security and licensing.
